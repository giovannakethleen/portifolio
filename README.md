# Portfólio Angular

Versão Angular do portfólio de Giovanna Kethleen, com tema espacial, animação
de estrelas, menu responsivo, projetos e canais de contato.

## Requisitos

- Node.js compatível com Angular 21 (Node.js 20.19+, 22.12+ ou 24+)
- npm

## Executar localmente

```bash
npm install
npm start
```

Acesse `http://localhost:4200/`. O servidor atualiza a página ao salvar
alterações nos arquivos.

## Build de produção

```bash
npm run build
```

Os arquivos de produção são gerados em `dist/`.

## Estrutura

- `src/app/app.ts`: dados do portfólio e interações Angular, incluindo canvas,
  menu mobile e animações de entrada.
- `src/app/app.html`: conteúdo e seções do portfólio.
- `src/styles.css`: tema, responsividade e estilos globais.
- `public/`: favicon e imagens originais do projeto.

Bootstrap, Bootstrap Icons e as fontes são carregados por CDN e exigem conexão
com a internet no navegador.
